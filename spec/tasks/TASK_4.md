- **Проект**: api (Laravel)

## Проблема
- При переходе по адресу http://localhost/docs и http://localhost отображается ошибка "File not found"
- Ожидаемое поведение: /docs — Swagger UI, / — информационная страница

## Структура проекта

- Swagger: provydon/docs-generate
- Документация генерируется в public/docs.json
- Swagger UI должен быть доступен по маршруту /docs
