# Архитектура сервиса forex-web (Laravel)

## Цель сервиса
Backend для управления Forex стратегиями, предоставляет REST API для фронтенда и взаимодействует с MCP-сервером для вызова необходимых микросервисов.

## Технологический стек (НЕИЗМЕНЯЕМО)
- **Язык:** PHP 8.2
- **Фреймворк:** Laravel 12
- **База данных:** PostgreSQL 15
- **Веб-сервер:** Nginx (в отдельном контейнере)
- **Контейнеризация:** Docker + docker-compose
- **Документация API:** Swagger (provydon/docs-generate)

## База данных
- Все миграции в database/migrations

## Маршруты
- Все API маршруты в routes/api.php
- Базовый префикс: /api/v1
